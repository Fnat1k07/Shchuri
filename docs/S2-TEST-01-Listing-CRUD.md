# S2-TEST-01 — Listing CRUD Testing

## 1. Мета тестування

Перевірка основних CRUD-операцій оголошень житла (Listing) у HomeRent, а також перевірка прав доступу користувачів залежно від їх ролі та авторизації.

## 2. Середовище тестування

- Backend: Django REST Framework
- Frontend: React
- Database: PostgreSQL
- Тип тестування: ручне функціональне тестування
- Об'єкт тестування: Listing

## 3. Тестові сценарії

### TC-01 — Create Listing

**Мета:** Перевірити створення нового оголошення власником.

**Дії:**
1. Авторизуватися під акаунтом власника.
2. Перейти до створення оголошення.
3. Заповнити поля оголошення.
4. Зберегти оголошення.

**Очікуваний результат:** Оголошення створюється, зберігається в базі даних і відображається в розділі «Мої оголошення».

**Фактичний результат:** Оголошення успішно створено та відображено у списку власних оголошень.

**Статус:** PASS

---

### TC-02 — Read Listing

**Мета:** Перевірити отримання та відображення даних оголошення.

**Дії:**
1. Перейти до розділу «Мої оголошення».
2. Знайти створене оголошення.
3. Перевірити його основні характеристики.
4. Відкрити форму редагування та перевірити наявність збережених даних.

**Очікуваний результат:** Дані оголошення коректно отримуються та відображаються.

**Фактичний результат:** Оголошення відображається в розділі власних оголошень. Дані коректно завантажуються у форму редагування. Перехід до окремої сторінки перегляду оголошення через картку не працює або не реалізований.

**Статус:** PASS (основне отримання та відображення даних)

---

### TC-03 — Update Listing

**Мета:** Перевірити редагування вже створеного оголошення.

**Дії:**
1. Відкрити власне оголошення в режимі редагування.
2. Змінити ціну з 12000 грн на 15000 грн.
3. Зберегти зміни.
4. Повторно відкрити список власних оголошень.

**Очікуваний результат:** Зміни зберігаються та відображаються після повторного завантаження даних.

**Фактичний результат:** Ціну успішно змінено на 15000 грн. Оновлене значення збереглося та відобразилося у списку оголошень.

**Статус:** PASS

---

### TC-04 — Delete Listing

**Мета:** Перевірити можливість видалення власного оголошення.

**Дії:**
1. Перейти до розділу «Мої оголошення».
2. Перевірити наявність функції видалення на картці оголошення.
3. Перевірити наявність функції видалення у формі редагування.

**Очікуваний результат:** Власник має можливість видалити своє оголошення.

**Фактичний результат:** Кнопка або інший елемент видалення оголошення в інтерфейсі не виявлений.

**Статус:** FAIL

**Виявлена проблема:** Функція видалення оголошення не доступна через користувацький інтерфейс.

---

### TC-05 — Authorization

**Мета:** Перевірити обмеження доступу до особистого кабінету для неавторизованих користувачів.

**Дії:**
1. Вийти з акаунта власника.
2. Спробувати отримати доступ до розділу «Мої оголошення».

**Очікуваний результат:** Неавторизований користувач не має доступу до особистого кабінету.

**Фактичний результат:** Доступ до розділу власних оголошень без авторизації недоступний.

**Статус:** PASS

---

### TC-06 — Renter Permissions

**Мета:** Перевірити обмеження функціональності для користувача з роллю орендаря.

**Дії:**
1. Створити та авторизуватися під акаунтом орендаря.
2. Спробувати отримати доступ до функції створення оголошення.

**Очікуваний результат:** Орендар не може створювати оголошення.

**Фактичний результат:** Функція створення оголошення для акаунта орендаря недоступна.

**Статус:** PASS

## 5. Висновок

Під час ручного функціонального тестування Listing CRUD у HomeRent підтверджено роботу створення, отримання та редагування оголошень. Також перевірено базові обмеження доступу для неавторизованих користувачів та орендарів.

Виявлено недолік — відсутність функції видалення оголошення в користувацькому інтерфейсі. Цю функціональність необхідно доопрацювати в наступних етапах розробки.
