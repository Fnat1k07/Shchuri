# HomeRent

HomeRent — вебплатформа для пошуку та оренди житла.

Користувач може переглядати оголошення про оренду житла, використовувати пошук і фільтри, переглядати детальну інформацію про об'єкти, додавати оголошення до обраного та надсилати заявки власникам.

Власник житла може створювати та редагувати власні оголошення, додавати фотографії, вказувати характеристики житла та керувати своїми оголошеннями.

## Основні можливості

### Для орендаря

* пошук оголошень про оренду житла;
* фільтрація та сортування оголошень;
* перегляд детальної інформації про житло;
* перегляд фотографій та характеристик;
* додавання оголошень до обраного;
* надсилання заявки власнику.

### Для власника

* створення оголошення;
* редагування власних оголошень;
* додавання та видалення фотографій;
* вказання ціни, адреси та характеристик житла;
* перегляд і керування власними оголошеннями;
* обробка заявок від орендарів.

## Технологічний стек

### Backend

* **Python**
* **Django** — основний backend-фреймворк;
* **Django REST Framework (DRF)** — створення REST API;
* **JWT** — авторизація користувачів.

### Frontend

* **React** — створення користувацького інтерфейсу;
* **React Router** — маршрутизація сторінок;
* **Axios** — взаємодія frontend із REST API.

### Database

* **PostgreSQL** — реляційна база даних;
* **Django ORM** — робота з базою даних через моделі Django.

### Інструменти

* **Git** — система контролю версій;
* **GitHub** — зберігання репозиторію та спільна робота над проєктом;
* **Swagger / OpenAPI** — документація REST API.

## Взаємодія компонентів

Frontend та backend взаємодіють через REST API.

Загальна схема роботи:

```text
Користувач
    ↓
React (Frontend)
    ↓
REST API
    ↓
Django + Django REST Framework
    ↓
Django ORM
    ↓
PostgreSQL
```

Frontend відповідає за відображення сторінок та взаємодію з користувачем.

Backend відповідає за бізнес-логіку, авторизацію, обробку запитів та взаємодію з базою даних.

PostgreSQL використовується для зберігання інформації про користувачів, оголошення, фотографії, характеристики житла, обране та заявки.

## Встановлення та запуск

Інструкція запуску буде доповнена після завершення початкового налаштування backend, frontend та PostgreSQL.

### Backend

Буде описано:

* створення та активацію віртуального середовища;
* встановлення залежностей;
* налаштування змінних середовища;
* підключення PostgreSQL;
* виконання міграцій;
* запуск Django-сервера.

### Frontend

Буде описано:

* встановлення залежностей;
* налаштування змінних середовища;
* запуск React-застосунку.

### Database

Буде описано:

* створення бази даних PostgreSQL;
* налаштування підключення;
* виконання Django-міграцій.

## Статус проєкту

Проєкт знаходиться на етапі початкового налаштування.

Поточний етап:

* створено GitHub-репозиторій;
* підготовлено базову структуру проєкту;
* створено `.gitignore`;
* підготовлено README;
* визначено технологічний стек.

Наступний етап — налаштування Django, Django REST Framework та базової backend-інфраструктури.
